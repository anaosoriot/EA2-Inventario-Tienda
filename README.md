# EA2 - Inventario de tienda de barrio (Java)

Programa de consola en Java para controlar el inventario de una tienda de barrio.
Los datos de productos son simulados.
Autora: Ana María Osorio - Tecnología en Desarrollo de Software.

## Cómo ejecutarlo
1. Instalar un JDK (versión 11 o superior).
2. Descargar InventarioTienda.java.
3. Compilar: javac InventarioTienda.java
4. Ejecutar: java InventarioTienda
